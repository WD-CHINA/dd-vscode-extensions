# 开发文档

## 目录

```text
extensions/          每个子目录是一个独立扩展
packages/shared/     可复用代码，包名 @dd-vscode-extensions/shared
tsconfig.base.json   所有包共用的 TypeScript 配置
.vscode/             调试配置和默认编译任务
```

`pnpm-workspace.yaml` 把 `extensions/*` 和 `packages/*` 收进同一个工作区。依赖装在仓库根的 `node_modules`（`.npmrc` 里 `node-linker=hoisted`），这样编辑器能找到 `@types/node`。

## 常用命令

在仓库根目录执行：

```bash
pnpm install          # 安装依赖
pnpm test             # 跑所有扩展的测试
pnpm run compile      # 编译共享包和全部扩展
pnpm run watch        # 监听编译
```

只处理一个扩展时，把目录换过去：

```bash
pnpm --filter warp-terminal run compile
pnpm --filter feishu-launcher test
pnpm --filter sourcetree-launcher run compile
```

## 调试

`.vscode/launch.json` 里每个扩展有一条 Extension Host 配置。`.vscode/tasks.json` 的默认生成任务是仓库根的 `pnpm run compile`，按 F5 会先编译再启动。

调试窗口里的扩展来自源码目录，不是已经安装的 vsix。改完 `package.json` 的贡献点后要重载调试窗口。

## 新增一个扩展

1. 复制 `extensions/feishu-launcher` 或 `extensions/sourcetree-launcher` 为新目录。启动单个应用用飞书那套；要带上当前项目或 Git 仓库时用 SourceTree 那套。
2. 修改 `package.json` 的 `name`、`displayName`、`description` 和状态栏命令。`publisher` 保持 `dd-vscode-extensions`，`engines.vscode` 保持 `^1.85.0`。不要加活动栏、侧边栏或资源管理器右键。
3. 源码放在 `src/`。入口是 `src/extension.ts`，`package.json` 的 `main` 指向 `./out/extension.js`。
4. 保留两份 TypeScript 配置，不要合并成一份：
   - `tsconfig.json`：包含测试，`noEmit: true`，给编辑器做类型检查。
   - `tsconfig.build.json`：排除 `src/**/*.test.ts`，输出到 `out/`。
   - `compile` / `watch` 脚本使用 `tsc -p tsconfig.build.json`。
5. 在 `.vscode/launch.json` 加一条配置，`extensionDevelopmentPath` 指到新目录。
6. 写 `README.md`，只描述状态栏怎么打开，不写开发步骤。
7. 跑 `pnpm install`，再跑这个扩展的 `test` 和 `compile`。

工作区用 `extensions/*` 匹配目录，新扩展不用改 `pnpm-workspace.yaml`。

## 测试

测试放在 `src/*.test.ts`，用 Node 内置测试：

```bash
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test src/<name>.test.ts
```

测试文件之间用 `.ts` 后缀导入。被测试的实现不要依赖 `vscode` 模块，方便直接用 Node 跑。需要临时目录时用 `mkdtemp`，结束时删掉。

## 打包和安装

必须在扩展目录里打包。在仓库根执行会读到根 `package.json`，它没有 `engines`，`vsce` 会失败。

```bash
cd extensions/warp-terminal
pnpm dlx @vscode/vsce package --allow-missing-repository --no-dependencies
```

飞书、SourceTree 把目录换成对应扩展即可。产物是当前目录下的 `<name>-<version>.vsix`，已被 git 忽略。

装进当前 Cursor：

```bash
cursor --install-extension ./warp-terminal-0.1.0.vsix --force
```

安装后重新加载窗口。发布者是 `dd-vscode-extensions`，扩展 id 形如 `dd-vscode-extensions.warp-terminal`。
